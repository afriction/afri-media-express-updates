# Confidentialité — Afri Media Express

Creative tools by Robin Kapka · 27 octobre 2026

L’extension détecte les médias des pages visitées afin de les proposer dans son panneau. Les titres, adresses de médias et métadonnées de la file sont conservés localement dans le navigateur pour suivre les traitements.

Lorsque vous lancez un téléchargement ou choisissez d’ouvrir un média dans l’application, l’adresse sélectionnée, son titre, le format et les réglages nécessaires sont communiqués à l’application Afri Media Express installée sur votre ordinateur. Les fichiers sont récupérés auprès du site concerné et convertis localement. Les cookies et mots de passe du navigateur ne sont pas transmis à cette application.

Aucun service distant de conversion, compte Afri Media Express, publicité, outil de mesure d’audience ou télémétrie n’est utilisé. L’extension n’envoie pas votre historique de navigation général à un serveur de collecte.

Firefox consulte l’adresse de mises à jour hébergée sur GitHub et télécharge les versions signées par Mozilla. GitHub et les sites de médias reçoivent les informations réseau habituelles nécessaires à ces requêtes, notamment l’adresse IP.

Vider la progression retire les enregistrements de la file sans supprimer les fichiers exportés. Désinstaller l’extension retire ses données du navigateur ; les fichiers enregistrés sur l’ordinateur restent disponibles.
